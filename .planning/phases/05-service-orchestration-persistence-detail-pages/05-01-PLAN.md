# Plan 05-01: Wire Launch Service Return and Launch Page Persistence

## Objective

Modify `TokenLaunchService.launchToken()` to return `TokenFormData` alongside `TokenLaunchConfig`, then update the launch page's success handler to POST all user-configured parameters to `/api/tokens/create` so the database receives every launch choice.

---

## Tasks

### Task 1: Create `LaunchResult` interface and update `launchToken()` return type

**`<read_first>`**
- `lib/services/launchService.ts` (current return type on line 45: `Promise<TokenLaunchConfig>`)
- `types/token.ts` (`TokenFormData`, `TokenLaunchConfig`, `TokenMetadata`)
- `config/defaults.ts` (default values used as fallbacks in `launchToken`)
- `.planning/phases/05-service-orchestration-persistence-detail-pages/05-CONTEXT.md` (D-05-05)

**`<action>`**
1. In `types/token.ts`, add the `LaunchResult` interface (insert after `TokenLaunchConfig`):
   ```typescript
   export interface LaunchResult {
     config: TokenLaunchConfig;
     formData: TokenFormData;
   }
   ```
2. In `lib/services/launchService.ts`:
   - Change the import on line 2 to include `LaunchResult`:
     ```typescript
     import { TokenFormData, LaunchStatus, TokenLaunchConfig, LaunchResult } from "@/types/token";
     ```
   - Change the method signature on line 45 from `Promise<TokenLaunchConfig>` to `Promise<LaunchResult>`.
   - Locate the final return at the bottom of the method (currently line 521: `return launchConfig;`).
   - Replace it with:
     ```typescript
     const result: LaunchResult = {
       config: launchConfig,
       formData,
     };
     return result;
     ```
   - `formData` is already in scope because it's the first parameter of `launchToken`.

**`<acceptance_criteria>`**
- `grep "LaunchResult" types/token.ts` returns a match (the interface definition)
- `grep "LaunchResult" lib/services/launchService.ts` shows both import and method signature
- `grep "formData" lib/services/launchService.ts | tail -1` shows `return result` referencing the original `formData` parameter
- `npx tsc --noEmit` compiles with zero errors
- `npm run lint` passes with zero errors
