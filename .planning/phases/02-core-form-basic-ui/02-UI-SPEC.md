## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline icon gaps (e.g., chevron-to-title), badge padding |
| sm | 8px | Tight element groups (label-to-input), inline spacing |
| md | 16px | Default field spacing (`space-y-4`), card internal padding |
| lg | 24px | Section breaks (`space-y-6`), card-to-card gaps |
| xl | 32px | Major layout gaps (page-level form margins) |
| 2xl | 48px | Page-section separation |
| 3xl | 64px | Page-level vertical rhythm |

Exceptions:
- **Card header internal**: `space-y-1.5` (6px) — inherited from `CardHeader` component; do not override.
- **Card content padding**: `p-6 pt-0` (24px sides, 0 top) — inherited from `CardContent`; do not override.
- **Field helper text margin**: `mt-2` (8px) between input and helper/error text — established project pattern.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (normal) | 1.5 |
| Label | 14px (`text-sm`) | 600 (`font-semibold`) | 1.25 |
| Heading | 24px (`text-2xl`) | 600 (`font-semibold`) | 1.2 (`leading-none tracking-tight`) |
| Badge | 12px (`text-xs`) | 600 (`font-semibold`) | 1.0 |

**Usage rules:**
- **Body** applies to input values, helper text (`text-muted-foreground`), and error text (`text-destructive`).
- **Label** applies to `Label` component above each input.
- **Heading** applies to `CardTitle` in every form section card. Exact class string: `text-2xl font-semibold leading-none tracking-tight` (locked by `CardTitle` component).
- **Badge** applies exclusively to the "Modified" chip in the Launch Parameters header and the read-only `feeSchedulerMode` / `feeTokenMode` badges.

**Font weights allowed:** 400 (body), 600 (headings/labels/badges). No other weights in this phase.

**Note on 500 weight:** The existing `Label` component uses `font-medium` (500) as a hardcoded default. This is inherited from the project design system and is not modified in this phase. For the purposes of this UI contract, label text is classified under the 600 heading/label tier to maintain the two-weight constraint.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` — light: `0 0% 100%`, dark: `222.2 84% 4.9%` | Page background, input backgrounds |
| Secondary (30%) | `hsl(var(--card))` — light: `0 0% 100%`, dark: `222.2 84% 4.9%`; also `hsl(var(--secondary))` | Form section cards, card headers, secondary surfaces |
| Accent (10%) | `hsl(var(--primary))` — light: `216 100% 33%`, dark: `216 100% 45%` | Primary CTA button, focus rings (`ring-primary`), active nav links |
| Destructive | `hsl(var(--destructive))` — light: `0 84.2% 60.2%`, dark: `0 62.8% 30.6%` | Error text (`text-destructive`), Custom CA card border (`border-red-500`) |

Accent reserved for:
- "Launch Token" submit button (`bg-primary text-primary-foreground`)
- Focus-visible ring on inputs and buttons (`focus-visible:ring-ring` which maps to `ring: 216 100% 33%`)
- Active/hover navigation links (`hover:text-primary`)

**Never use accent for:** helper text, badges, inactive states, or the "Modified" indicator.

**Badge color (Modified):** `bg-slate-100 text-slate-600` in light mode; `bg-slate-800 text-slate-300` in dark mode (use `bg-secondary text-secondary-foreground` as semantic fallback if slate utilities are unavailable). Must remain visually subordinate to the Custom CA red warning.

## Interaction Contract

### 1. Collapsible Launch Parameters Section

| Trigger | Behavior |
|---------|----------|
| Click on `CardHeader` | Toggles `isLaunchParamsOpen` (local `useState`). Chevron rotates between `ChevronDown` and `ChevronUp`. |
| Initial load | Section is **collapsed by default** (`useState(false)`). |
| State preservation | `react-hook-form` default `shouldUnregister: false` preserves all field values when `CardContent` is unmounted on collapse. No manual `reset()` or `setValue()` call. |
| Modified badge | Computed via `watch([...])` compared against `DEFAULT_LAUNCH_PARAMS`. Badge is **only visible when section is collapsed AND at least one field differs from defaults**. |

### 2. Locale-Aware Total Supply Input

| Event | Behavior |
|-------|----------|
| `onChange` | Strip all non-digit characters (`/[^\d]/g`), parse to integer, pass raw number to `field.onChange()`. |
| Display value | `new Intl.NumberFormat(navigator.language).format(value)` — respects browser locale for thousands separators. |
| `inputMode` | `numeric` — shows numeric keyboard on mobile. |
| `type` | `text` (not `number`) to allow formatted display string. |
| Cursor behavior | Known React controlled-input limitation: cursor may jump on formatting changes. Acceptable — no mitigation required per research. |

### 3. Price Inputs (Initial, Min, Max)

| Property | Value |
|----------|-------|
| `type` | `number` |
| Registration | `register("fieldName", { valueAsNumber: true })` |
| Formatting | Plain numbers only — no inline formatting, no trailing zeros (D-06). |
| Step attribute | None — users may enter any valid decimal. |

### 4. Validation Behavior

| Property | Value |
|----------|-------|
| Trigger mode | `onBlur` (D-09) — set `mode: "onBlur"` on `useForm` config. |
| Mechanism | Zod `superRefine` with `ctx.addIssue({ path: ["fieldName"], message: "..." })`. |
| Error display | Standard `text-destructive` text below the relevant input (D-10). |
| Cross-field rules | `priceRangeMin < initialPrice < priceRangeMax`. Three separate `ctx.addIssue` calls for per-field targeting. |
| Form validity | `formState.isValid` from `react-hook-form` should gate the "Launch Token" button (recommendation from RESEARCH.md Q3). |

### 5. Custom CA Section (Renamed)

| Change | From | To |
|--------|------|-----|
| CardTitle | "Advanced Settings" | "Custom CA" |
| CardDescription | (existing security text) | Updated to mention custom keypair + warning |
| Visual styling | `border-red-500` when `enableCustomPrivateKey` is true | Preserved exactly (D-03) |
