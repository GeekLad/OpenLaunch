# Plan 03-01: Install Radix UI Primitives & Create Component Wrappers

## Objective

Install 5 `@radix-ui/react-*` packages and create corresponding `cn()` wrapper components in `components/ui/`, matching the existing project pattern (e.g., `components/ui/button.tsx`, `components/ui/card.tsx`).

## Background

Phase 2 added supply/price fields using existing primitives (`Input`, `Label`, `Card`, `Button`). Phase 3 requires new interaction primitives:
- **Slider**: holdback percentage (0–100%)
- **Select**: quote token (SOL/USDC), fee scheduler mode (market-cap/time/fixed)
- **Dialog**: launch confirmation modal
- **Alert**: red-flag warning banner when holdback > 10%
- **Badge**: "Modified" badge and collapsed holdback warning badge
- **RadioGroup**: fee token mode (quote-only / both-tokens)

All existing UI components in this project are custom `class-variance-authority` + `tailwind-merge` wrappers over Radix primitives (`cn()` utility). There is NO `components.json` shadcn CLI integration.
