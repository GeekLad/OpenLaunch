# Plan 04-01: Fix Holdback Math and Quote Token Decimals

## Objective

Correct the backwards holdback calculation and replace the hardcoded `tokenBDecimals: 9` with a dynamic lookup based on the selected quote token (SOL = 9 decimals, USDC = 6 decimals). These are prerequisite fixes for all subsequent on-chain parameter mapping.

---

## Tasks

### Task 1: Fix holdback math in `launchService.ts`

**`<read_first>`**
- `lib/services/launchService.ts` (lines 180–195)
- `config/defaults.ts` (verify `DEFAULT_HOLDBACK_PERCENTAGE` default)
- `.planning/phases/04-blockchain-integration-pre-flight-safety/04-CONTEXT.md` (D-01 through D-04)

**`<action>`**
1. On line 188 of `launchService.ts`, change `poolTokenAmount` formula from:
   - `Math.floor(totalSupply * holdbackPercentage / 100)`
   - To: `Math.floor(totalSupply * (100 - holdbackPercentage) / 100)`
2. Update the console log on lines 190–195 that prints "Token amount" and "Market cap at launch" to reflect the corrected math.
3. Ensure the same fix is applied to the three additional `createDAMMv2Pool` calls on lines 278, 425, and any other duplicate pool creation calls.

**`<acceptance_criteria>`**
- `grep "holdbackPercentage" lib/services/launchService.ts | grep -v "(100 -"` returns zero matches inside `poolTokenAmount` calculations
- `grep -n "poolTokenAmount" lib/services/launchService.ts` shows the formula uses `(100 - holdbackPercentage)`
- `npm run lint` passes with zero errors

### Task 2: Add quote token decimals lookup and pass dynamic `tokenBDecimals`

**`<read_first>`**
- `lib/services/launchService.ts` (lines 213–226, 278–291, 425–438)
- `lib/solana/poolUtils.ts` (lines 54–75, `CreatePoolParams` interface)
- `config/defaults.ts` (verify `DEFAULT_QUOTE_TOKEN_MINT` values)
- `types/token.ts` (verify `quoteTokenMint` field type)

**`<action>`**
1. In `config/defaults.ts`, add a constant `QUOTE_TOKEN_DECIMALS` mapping:
   - `So11111111111111111111111111111111111111112` → `9`
   - `EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v` → `6`
2. Export a helper function `getQuoteTokenDecimals(mintAddress: string): number` that returns the mapped value or throws for unknown mints.
3. In `launchService.ts`, replace every hardcoded `tokenBDecimals: 9` (lines 220, 285, 432) with `tokenBDecimals: getQuoteTokenDecimals(formData.quoteTokenMint ?? DEFAULT_LAUNCH_PARAMS.quoteTokenMint)`.
4. If `CreatePoolParams` in `poolUtils.ts` does not already have a `collectFeeMode` parameter, add `collectFeeMode?: CollectFeeMode` to the interface — this prepares the parameter for Plan 04-02.

**`<acceptance_criteria>`**
- `grep -n "tokenBDecimals: 9" lib/services/launchService.ts` returns zero matches
- `config/defaults.ts` contains `getQuoteTokenDecimals(quoteTokenMint: string)`
- `npm run lint` passes
- `npx tsc --noEmit` compiles without type errors
